# 핏체크

피부 프로필과 화장품 사용 기록을 바탕으로 성분과 사용감을 비교하는 정적 웹사이트입니다.

- 웹사이트: https://gracegz1125-web.github.io/-my-website/
- 시작 파일: `index.html`
- GitHub Pages: `main` 브랜치의 `/(root)`에서 배포
- 빌드 또는 서버 설치 없이 동작합니다.

## 데이터와 기능 범위

사용 기록과 프로필은 해당 브라우저의 저장소에 보관됩니다. 로그인·서버 저장·자동 기기 간 동기화는 제공하지 않습니다. JSON 내보내기와 불러오기로 기록을 옮길 수 있습니다.

글꼴과 사진 OCR 엔진은 외부 CDN을 사용하므로 인터넷 연결이 필요합니다. OCR은 브라우저에서 처리됩니다.

추천 카탈로그는 가상 제품 예시입니다. 성분 점수와 근거 등급은 원본 프로토타입의 참고용 규칙이며 의학적 검증을 의미하지 않습니다. 프리미엄 관심 표시는 브라우저에만 저장되며 결제나 실제 알림 접수가 아닙니다.

## 수정 방법

`index.html`을 수정해 `main`에 커밋하면 GitHub Pages가 다시 배포합니다. 브라우저 데이터를 지우기 전 기록을 내보내세요.
